# Manual do utilizador — ARTSOFT para n8n

Este manual explica, sem linguagem técnica desnecessária, como instalar, configurar e usar o **node ARTSOFT** no n8n. Com ele, os seus fluxos automáticos (os "workflows" do n8n) podem criar, consultar, alterar e apagar informação no ARTSOFT: clientes, fornecedores, artigos, documentos, fluxos de trabalho e eventos de CRM.

## Uma nota sobre os nomes no ecrã

O node apresenta os nomes dos campos em **inglês** (por exemplo *Customer*, *Create*, *Notes*), com exceção de dois títulos que aparecem em português: **Recurso** e **Operação**. Neste manual, os nomes que vê no ecrã estão sempre escritos **em negrito e em inglês**, para os encontrar facilmente. Entre parênteses aparece, em alguns campos, o nome interno do campo no ARTSOFT, por exemplo *Code (Cod.Codigo)*.

## Convenções

- **Obrigatório** — o campo tem de ser preenchido.
- **Opcional** — pode ficar vazio.
- Os exemplos usam valores fictícios. Substitua-os pelos seus.
